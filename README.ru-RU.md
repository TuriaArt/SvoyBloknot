## 💡 Введение

**SvoyBloknot** — личный форк [SiYuan Note](https://github.com/siyuan-note/siyuan), блочной системы управления знаниями с приоритетом на приватность: тонкая гранулярность блочных ссылок, WYSIWYG-редактирование Markdown, всё хранится локально.

Второе назначение проекта — бэкенд памяти для [SvoyAgent](https://github.com/TuriaArt/Meridian-Tu), персонального ИИ-агента: SvoyBloknot хранит историю диалогов и память агента как обычные заметки, без отдельной базы данных.

Полную официальную документацию по самой SiYuan смотрите в [апстриме](https://github.com/siyuan-note/siyuan) — здесь ниже описаны только возможности и то, чем конкретно этот форк отличается. Подробности решений и обоснования — в [ARCHITECTURE.md](ARCHITECTURE.md); что сделано и что дальше — в [ROADMAP.md](ROADMAP.md).

## 🧭 Философия

Полная версия — в [PHILOSOPHY.md](PHILOSOPHY.md). Коротко: SvoyBloknot существует ради тех же принципов, что и [SvoyAgent](https://github.com/TuriaArt/Meridian-Tu) — из его манифеста:

> ❌ Не скрывает функции за искусственными ограничениями.
>
> ❌ Не запирает данные пользователя в закрытом формате.

Оригинальный клиент SiYuan прячет часть функций (например, стороннюю синхронизацию) за подпиской, а данные при этом и так открыты и локальны — но сам факт искусственного ограничения противоречит этому принципу. Отсюда и этот форк: тот же код, та же лицензия, без скрытых за подпиской возможностей.

## 🆚 Чем этот форк отличается от оригинала

Оригинальный клиент SiYuan привязывает часть функций к официальной подписке/облаку. Здесь это убрано:

- **Сторонняя синхронизация (S3 / WebDAV / локальная папка) не требует подписки.** В оригинале это ограничение было не только косметическим — настройка этих провайдеров была заблокирована и на фронтенде, и в самом ядре без активной платной подписки SiYuan.
- **Иконка "не подписан" в верхней панели выключена по умолчанию** — не показывает предупреждение тем, кто никогда не логинился в облако SiYuan.
- **Никаких тостов "оплатите синхронизацию".**
- **Проверка обновлений и фоновая автозагрузка официальных пакетов SiYuan отключены** — апстрим не может незаметно предложить "обновиться" на официальный релиз поверх этого форка. Обновление SvoyBloknot — ручное действие (подтянуть апстрим, пересобрать).
- **Бренд**: имя приложения, ярлыка и установщика — SvoyBloknot вместо SiYuan.

Ничего из этого не меняет API ядра или API плагинов — существующие плагины и темы SiYuan совместимы без изменений.

## 🔮 Возможности

Всё, что умеет оригинальная SiYuan — доступно здесь без ограничений и без подписки:

- Блочный контент
  - Блочные ссылки и двусторонние связи
  - Пользовательские атрибуты блоков
  - Встраивание SQL-запросов
  - Протокол `siyuan://`
- Редактор
  - Блочный стиль
  - Markdown WYSIWYG
  - Оглавление по спискам
  - Приближение к блоку (zoom-in)
  - Редактирование документов на миллионы слов
  - Формулы, диаграммы, блок-схемы, диаграммы Ганта, нотный стан и т.д.
  - Веб-клиппер
  - Привязка PDF-аннотаций
- Экспорт
  - Ссылки и вставки блоков
  - Стандартный Markdown с ресурсами
  - PDF, Word, HTML
- База данных
  - Табличный вид
- Флеш-карточки с интервальным повторением
- ИИ-написание и чат вопрос/ответ через OpenAI-совместимый API
- Распознавание текста Tesseract OCR
- Несколько вкладок, разделение экрана перетаскиванием
- Шаблоны-сниппеты
- JavaScript/CSS-сниппеты
- [API ядра](https://github.com/siyuan-note/siyuan/blob/master/docs/API.md)
- Совместимость с готовыми плагинами и темами сообщества SiYuan

## 🛠️ Сборка из исходников

```bash
# Ядро (Go)
cd kernel && go build -o ../app/kernel/SiYuan-Kernel.exe .

# Приложение (Electron)
cd app
pnpm install
pnpm run build
pnpm run dist
```

Собранный установщик появится в `app/build/`.

## ⌨️ Интерфейс командной строки

Встроенный CLI даёт прямой доступ к данным рабочего пространства без запущенного сервера.

```bash
# Список всех блокнотов
siyuan notebook list -w ~/SiYuan

# Полнотекстовый поиск с выводом в JSON
siyuan search "ключевое слово" -w ~/SiYuan -f json

# Поиск внутри вложенных файлов (PDF/Word/Excel/txt и т.д.)
siyuan search "фраза" --asset -w ~/SiYuan

# Экспорт документа в Markdown
siyuan export md --id <block-id> -w ~/SiYuan
```

| Категория | Команды |
|---|---|
| Блокноты и документы | `notebook`, `document`, `dailynote` |
| Контент | `block`, `attr`, `outline` |
| Метаданные | `tag`, `bookmark`, `template` |
| Запросы | `search`, `sql` |
| Ссылки | `ref` |
| Импорт/экспорт | `export`, `import`, `inbox` |
| Управление данными | `repo`, `history`, `sync` |
| Утилиты | `asset`, `file` |
| База данных | `database` |
| Сервер | `serve` |
| Рабочее пространство и система | `workspace`, `system` |

Полное дерево команд — `siyuan --help`. Бинарник CLI — `<папка установки>/resources/kernel/SiYuan-Kernel.exe`, установщик Windows сам добавляет эту папку в `PATH`.

## ❓ Частые вопросы

**Нужно ли платить за что-либо?**
Нет. Именно это и есть смысл форка — сторонняя синхронизация и весь остальной функционал доступны без подписки.

**Поддерживается ли синхронизация через сторонний диск (WebDAV/S3/локальная папка)?**
Да, без ограничений и без подписки — в этом ключевое отличие от оригинала (см. раздел выше).

**Открыт ли исходный код?**
Да, полностью, лицензия AGPL-3.0-or-later — как у оригинальной SiYuan. Список изменений форка — в git-истории этого репозитория.

**Как обновиться до новой версии?**
Автообновление отключено намеренно. Чтобы обновиться — подтянуть новый коммит из [апстрима](https://github.com/siyuan-note/siyuan), заново применить патчи форка (см. git-историю) и пересобрать (см. раздел «Сборка из исходников»).

**Как устроено хранение данных?**
Так же, как в оригинале — данные лежат в папке рабочего пространства обычными файлами (`.sy` — JSON с содержимым документа), плюс отдельные подпапки под ресурсы, темы, плагины, шаблоны и т.д.

**Что делать, если потерян ключ репозитория данных?**
Как в оригинале — см. раздел `Settings → Account & Sync → Local Data Repo` внутри самого приложения; шаги идентичны официальной документации SiYuan.
